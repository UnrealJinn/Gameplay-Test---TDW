# Gameplay-Test- GAS-Based Leap Slam Implementation

## Overview

This project implements a modular Gameplay Ability System (GAS)
framework in Unreal Engine 5.5 using the Top-Down template as a base.
The primary objective was to design a scalable ARPG-oriented
architecture and implement the **Leap Slam** ability inspired by *Path
of Exile*.

The focus of this implementation is system design, extensibility,
scalability, and correct usage of Unreal's Gameplay Ability System.



# Engine & Template

-   **Engine Version:** Unreal Engine 5.5\
-   **Base Template:** Top-Down Template (C++)

The template was extended to support a modular GAS-driven combat
framework.
